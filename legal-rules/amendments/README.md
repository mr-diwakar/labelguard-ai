# Amendments

Later notifications amend the 2011 Rules. Phase 6 does **not** encode those amendments as verified law.

A secondary compilation reports that G.S.R. 629(E) dated 23 June 2017 inserted Rule 6(1)(aa) (country of origin on imported products). That clause is **not** in the official 2011 India Code text used for the verified seed. `LM-PC-ORIGIN-001` is stored as `DRAFT` / `UNVERIFIED` until someone checks the DoCA consolidated publication and updates `source_reference` and `verification_status`.

When an amendment is verified:

1. Close the previous version (`effective_to`).
2. Insert a new version (`effective_from` = amendment date).
3. Never delete the old row.
